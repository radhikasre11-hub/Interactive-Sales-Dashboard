INTERACTIVE SALES DASHBOARD — TABLEAU

Project overview
This Tableau dashboard analyzes sales performance using the US Superstore Orders dataset.

Dashboard contents
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Profit Margin KPI
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products

Tools
- Tableau Desktop/Public
- Superstore Orders dataset

How to open
1. Open Interactive_Sales_Dashboard_Final.twb in Tableau.
2. If Tableau asks for the data source, reconnect it to the same Superstore Orders dataset used in the original workbook.
3. Verify all worksheets render, then save or export a dashboard image for submission.

Note
The provided workbook is a .twb file, which stores workbook structure but does not necessarily embed the dataset. Keep the original dataset available when opening it on another computer. The dashboard layout has been adjusted to align four KPI cards in the top row and four charts in a two-by-two grid.
